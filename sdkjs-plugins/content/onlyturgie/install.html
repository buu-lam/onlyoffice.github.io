Installer Onlyturgie

Autocomplétion des chants et aperçus PDF/PPT dans OnlyOffice. Aucun mot de passe ni jeton à recopier.

  1. Ajouter le bouton à vos favoris

    Faites glisser ce bouton dans la barre de favoris de votre navigateur :

    ⛪ Connecter Onlyturgie

    Barre de favoris invisible ? Ctrl+Maj+B (Chrome, Edge, Firefox).

  2. Ouvrir le Gestionnaire de modules

    Ouvrez un document dans Nextcloud, onglet Modules complémentaires → Gestionnaire de modules. Laissez cette fenêtre ouverte.

    Inutile d’ajouter un magasin ou de passer en mode développeur : le favori s’en charge.

  3. Cliquer sur le favori

    Cliquez sur ⛪ Connecter Onlyturgie dans la barre de favoris. Il installe Onlyturgie et le relie à votre compte.

    Un message confirme. C’est fini : à faire une seule fois par navigateur. Plus tard, si Onlyturgie demande à être reconnecté, recliquez simplement sur le favori (le Gestionnaire n’est plus nécessaire).

    Onlyturgie reste grisé ? Onglet Modules complémentaires → bouton Plugins d’arrière-plan → activez l’interrupteur d’Onlyturgie (une seule fois), puis recliquez sur le favori.

    Votre compte Nextcloud doit appartenir à l’un des groupes : admin, animateurs, musiciens ou informatique.
